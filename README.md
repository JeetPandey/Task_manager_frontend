# Task Manager

A full-stack Task Management System built with React, Django REST Framework, JWT Authentication, and MySQL.

## Features

- JWT Authentication
- Task CRUD
- Search
- Filter
- Sorting
- Pagination
- Comments
- Kanban Board
- PDF Export
- Excel Export

## Tech Stack

Frontend:
- React
- Bootstrap
- Axios

Backend:
- Django
- Django REST Framework
- MySQL
- JWT Authentication

## Setup

### Backend

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm start
```
